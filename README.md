# Java Environment Setup

**Name:** Ysengrin Yerna  
**Description:** The purpose of this project was to set up a Java development environment with an IDE,
ensuring that programs could compile and that all required modules functioned.  
**IDE Used:** JetBrains IntelliJ IDEA  
**Java Version Used:** 21.0.11  
**Instructions for Running the Program:** First, ensure that the Java JDK is installed, then build the program with
the terminal command `javac Main.java`. Afterwards, run the program with the command `java Main`.
